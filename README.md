# Kursat Kilic’s research portfolio

The portfolio is a static site served directly from the repository root. Open `index.html` or serve this directory with `python -m http.server` for local review.

Edit `index.html` for research, bibliographic records and citation text. Publication search and topic selection are implemented in `data.js`. Navigation and citation copying are enhanced by `script.js`. All reading content and links are available in HTML.

The hero includes two illustrative tunnel views. **Inspect in 3D** opens a local lining model with rotation and separation controls. The Selected research figure switches between the Sakae model and its geological section. Image and model provenance is in the asset credits.
